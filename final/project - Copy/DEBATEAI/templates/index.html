      💡 How the Multi-Agent Debate Works

      Understanding the end-to-end workflow behind ConsensusAI.

      1. Supervisor Orchestration & Domain Identification

      When you ask a question, the Supervisor Agent examines the topic and determines which specialist domains (Technical, Cost, Risk, Security, Business) are necessary to produce a fair, balanced debate.

      2. Multi-Agent Deliberation

      Each specialist agent independently analyzes your scenario through its specialized lens, formulating a stance, listing reasons, and flagging domain-specific risks.

      3. Adversarial Critique & Fact-Checking

      The Critic Agent challenges the arguments to prevent bias or overconfidence, while the Verification Agent checks factual claims against evidence.

      4. Final Synthesis & Decision

      The Decision Agent merges all agent viewpoints into a single clear recommendation with supporting pillars, risks, and a weighted consensus confidence score.
